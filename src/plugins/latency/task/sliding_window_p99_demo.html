窗口详情

怎么看

每个指标独立一张图：total_latency、c2w_latency、w2w_urma_latency、urma_link_latency、query_meta_latency 各一条曲线，可以分别观察哪个指标出现劣化。

同时间戳并排：x 轴是时间戳，如果同一秒有多条数据（如并发请求），它们在 x 轴上紧挨着排列，时间标签可以连续重复（如 12:00, 12:00, 12:01...）。

滑动窗口 P99：以每个点为中心，前后各取半窗口的数据，计算该窗口内的 P99。紫色曲线就是各点的窗口 P99。

指标切换：点击顶部指标按钮可以显示/隐藏对应图表。
