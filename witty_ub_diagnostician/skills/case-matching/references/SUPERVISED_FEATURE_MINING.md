# 用真实标签挖掘日志表征

这里寻找的是日志模式与故障标签的统计映射，不要求日志必须直接陈述根因。
统一单位数值表示已作为默认分类器输入，配合全特征余弦 K4 退化；正式调用见
[默认标签策略](DEFAULT_LABEL_POLICY.md)。本页其他表示仍属于离线研究对照。

## 特征提取

`scripts/mined_log_features.py` 只读取真实日志消息列与有限的角色、静态组件、等级上下文：

- E/W 的角色＋组件词语/短语，对比原来无上下文的词袋。
- 加入 INFO 的上下文词语，保留成功慢调用和正常操作的背景分布。
- 去身份消息模板，移除行号、日期、地址、主机/集群、PID、trace、对象键和随机数字。
- 已测量的数值：状态/返回码、访问操作、耗时/大小、同一消息中的阶段等待占比及固定分桶。
- 等级比例、组件活动、同进程相邻模式与高频模式组合。进程身份只用于局部事件分组，不成为键。
- 测试/注入/GT 注释不参与特征，目录场景名只用于结果追溯与支持场景计数。

提取器不接收标签。标签只在离线训练中用来筛选和加权这些观测；不能由根因名反填查询事件。
INFO 也属于观测，不能把“成功调用”当成场景健康，更不能把统计关联称为因果证明。

`scripts/mined_log_features_v2.py` 在同一消息边界上补充以下候选观测：

- 保留带单位的小数，耗时统一到微秒、大小统一到字节；未知单位不猜测。
- 按静态组件、阶段及显式状态分别统计均值、极值、样本数、对数直方图和近似分位桶。
- 仅在同时存在显式成功、失败观测时计算两组的耗时比例与失败占比；W/E 等级本身不等于调用失败。
- 相对首条 W/E 的事件时间窗；不使用绝对日期。

第一版数值解析对紧接单位的小数支持不足，保留为原型对照。新研究优先使用第二版统一单位的表示，
不要因为第一版的训练内分数稍高就把解析缺陷固化为运行时规则。

## 学习映射

仓库根 `scripts/fault_label_loo/mine_label_features.py` 使用 `/home/witty-ub-logs/gt_labels.json`
核对真实标签，并原样复用 v5 的 379/95 来源划分与训练内部 3 折。

比较 v5 原特征、上下文 E/W、上下文 I/W/E、模板、数值、组合/顺序、上下文合并及其与 v5 合并的八种表示。
训练内部比较 Logistic C=0.1/1、自然/平衡类别权重、是否用 chi-square 选 500 个特征。
词表、缩放、监督选择与模型权重仅用相应训练折。所有选择先保存，再计算固定验证集输出。

另比较这些表示的余弦 K4，以及训练标签选择/加权后的余弦 K4。这里相似度已由新表示定义，
不是简单叠加到 v5 原评分；报告会分开标明。监督特征字典/度量也是训练产物，不能全数据拟合后评估同批留出样本。

训练标签还生成模式关联清单，记录支持报告数、标签命中数、条件比例、提升倍数和跨场景支持数。
低支持、单场景模式只作为线索，不升级为普遍规则。

第二轮 `mine_label_features_v2.py` 另比较单位、阶段/状态、显式成功失败对照、相对时间及其合并，
并加入“训练支持至少 3 份报告后最多选 1000 维”的选择对照。
`compare_feature_mappings.py` 进一步在同一划分比较线性/核方法与树模型，检查映射方式的限制。
这些离线实验需要实验目录的 Python 依赖；普通 Agent 不依赖 sklearn。

## 显式候选推理

`scripts/classify_mined_log.py --report REPORT --log-dir LOG_DIR --model MODEL --out RESULT`
使用与离线缓存相同的提取器，读取候选模型元数据选择第一版或第二版表示。
它只导出显式候选标签与分数，使用标准库，无需读取 GT，不改写诊断报告。
普通报告应使用 `generate_report.py` 和内置部署模型，不直接用这条候选 CLI 代替报告流程。
需要使用这一候选时显式指定对应实验产出的模型；不能把它直接传给只接受 v5 观测的默认分类器入口。

一组特征在某个分类器上有收益，不代表在原 K4 上同样有效；两个路径的实测指标分别查看。
总体准确率提高时，同时检查少数类别召回和宏 F1，避免仅因倾向硬件多数类而误判改进。

本批验证成绩已被查看过，因此这是开发性特征研究，不是新的独立外部测试。
候选表示能否提升以固定划分的实际结果为准，不根据验证成绩换种子或覆盖旧指标。
结果在 `/home/witty-ub-logs/loo_1117_v5/feature_mining/`；运行说明见仓库根实验 README。
